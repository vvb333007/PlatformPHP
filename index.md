# PlatformPHP — A Small Computer for Your Devices

Imagine a small computer. Instead of a monitor, keyboard, and mouse, it has dozens of connections where you can attach all kinds of devices: lights, relays, sensors, motors, buttons, displays, modems, GPS receivers, and almost any other electronic equipment.

That's the idea behind PlatformPHP.

Inside this little box, you have everything needed to run independently: its own software environment, a command shell, the PHP programming language, and a built-in web server.

In other words, it's a small computer with its own built-in operating environment. It can run on its own, without being permanently connected to another computer.

**What can it do?**

You can program it to perform almost any task involving the devices connected to it.

For example, you can make it:
- Turn the lights on automatically when it gets dark.
- Start a water pump when a sensor detects that the water level is too low.
- Run a greenhouse, controlling irrigation, lighting, and ventilation automatically.
- Send messages using a GSM modem.
- Receive GPS coordinates and track movement.
- Control gates, lighting, or other equipment over the Internet.

All of this can happen automatically, around the clock, without human intervention.

**You can control it over the Internet.**

PlatformPHP comes with a built-in web server. This means you can create a web page, open it on your phone or computer, and control your connected equipment: switch relays on and off, check sensor readings, change settings, and monitor the system.

No dedicated mobile app is required. All you need is an ordinary web browser.

**What if the built-in features aren't enough?**

PlatformPHP can be extended with your own programs. When needed, you can add regular C/C++ code that runs alongside the main system and provides support for additional hardware and functionality.

For everyday tasks, however, writing small PHP programs is usually all you need. You don't have to rebuild the firmware or deal with the complexities of microcontroller development every time you want to change how your system works.

**The possibilities are limited not so much by the built-in features, but by your imagination and the hardware you choose to connect.**

PlatformPHP turns a small microcontroller into a standalone programmable computer that can be adapted to almost any automation, control, or data-collection task.
